# ARMANO V6.1 — Dynamic Colour Environment Report

## 1. Executive Summary
The primary requirement of V6.1 was establishing a synchronized, whole-stage theme transition when selecting color swatches. Rather than merely changing the diffuse tint of the 3D model, the entire hero environment—including radial ambient lighting, background gradient, typography contrast, CTA accents, studio lights, and contact shadow—now transitions seamlessly as one unified luxury atmosphere.

## 3. Coordinated Transition Mechanics

### 3.1 Timing & Easing Curves
- **DOM Background & Typography:** Driven by `transition: all 1000ms cubic-bezier(0.16, 1, 0.3, 1)`.
- **Three.js Directional & Ambient Lights:** Smoothly lerped at `0.1` per frame delta inside the R3F frame loop:
  ```javascript
  keyLightRef.current.color.lerp(new THREE.Color(theme.keyLightColor), 0.1);
  keyLightRef.current.intensity = THREE.MathUtils.lerp(
    keyLightRef.current.intensity,
    theme.keyLightIntensity,
    0.1
  );
  ```
- **PBR Material Swapping:** Three.js receives the updated `theme` object directly, triggering reactive shader uniform updates without recompiling materials or causing hitching.

### 3.2 Visual Concept Labelling
To maintain strict compliance with B2B manufacturing transparency, all swatch interactions display:
- **Concept Badging:** `COLOUR CONCEPT • [Theme Name]`.
- **Disclaimers:** *"Visual Concept Model • Production materials verified during physical sampling"*. No claims are made that these represent unverified factory stock.
