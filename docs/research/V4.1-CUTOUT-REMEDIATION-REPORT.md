## 2. Forensic Analysis of the Four Rejected Assets

Visual inspection confirmed critical segmentation failures across the four sample assets:

### 2.1 Sample Velvet Clutch (`sample-velvet-clutch.jpg` / AR-002 Velvet / `image copy 23.png`)
- **Native Resolution**: 749 × 989 px
- **Visual Staging**: Staged on a carved luxury mantle/table with an ornate gold mirror frame, daylight window, and marble table surface.
- **Observed Failures**:
  - The flood-fill algorithm could not distinguish the dark lower boundary of the black velvet bag from the shadowed marble table, resulting in jagged, torn base contours.
  - Chunks of the ornate gold mirror frame and daylight window reflection remained attached to the perimeter.
  - The gold tassel pull and charm were partially eroded and fragmented.
- **Verdict**: **REJECTED (FAIL)**. The authentic original photograph (`image copy 23.png`) is restored on the storefront.

### 2.2 Sample Brush Belt (`sample-brush-belt.jpg` / AR-008 / `image copy 16.png`)
- **Native Resolution**: 1280 × 1134 px
- **Visual Staging**: Staged on a solid peach/terracotta sweep (`#FBDED6`).
- **Observed Failures**:
  - **Prominent Pink Halo**: Boundary semi-transparent pixels retained background light scatter (`R:251, G:222, B:214`). When composited against dark surfaces (e.g. Forest Green `#10352C`) or Warm Ivory (`#F7F4EF`), a prominent 2–4 pixel pink ring glowed around all straps, buckles, and bristle tips.
  - **Opaque Loop Islands**: The exterior flood-fill only traversed connected border pixels. Enclosed negative spaces inside belt loops, strap gaps, and buckle holes remained completely solid pink.
  - **Bristle Damage**: Fine makeup brush bristles were either clipped bluntly or surrounded by pink matting bleed.
- **Verdict**: **REJECTED (FAIL)**. The authentic original photograph (`image copy 16.png`) is restored on the storefront.

### 2.3 Sample Pink Tote (`sample-tote.jpg` / AR-011 / `image copy 11.png`)
- **Native Resolution**: 1600 × 1200 px
- **Visual Staging**: Staged on a studio tabletop with ambient vignette lighting (dark upper corners, warm gray table base).
- **Observed Failures**:
  - **Tone-on-Tone Chroma Collision**: The product is pastel blush pink (`RGB ~ 172, 137, 131`), which closely overlaps with the warm ambient tones of the background.
  - Setting a threshold high enough to clear the background ate directly into the leatherette seams, handles, and side panels.
  - Setting a conservative threshold left dirty gray table remnants and shadow islands below the base.
- **Verdict**: **REJECTED (FAIL)**. The authentic original photograph (`image copy 11.png`) is restored on the storefront.

### 2.4 AR-001 Trio (`AR-001.jpg` / `image copy 5.png`)
- **Native Resolution**: 1600 × 1200 px
- **Visual Staging**: Three cosmetic pouches (white PU, pink curved, fuchsia nylon) staged as a group composition on a natural wood table with background curtains.
- **Observed Failures**:
  - The flood-fill algorithm completely fractured on the wood grain texture, knot patterns, and curtain folds.
  - Left extensive patches of wooden table between and beneath the pouches.
  - Severely eroded the clean rectangular edges of the white pouch and the soft curves of the fuchsia pouch.
- **Verdict**: **REJECTED (FAIL)**. The authentic original photograph (`image copy 5.png`) is restored on the storefront.

## 3. Analysis of Contextual & Material Failures (AR-012 & AR-013)

### 3.1 AR-012 Clear Transparent PVC Window (`image copy 12.png`)
- **Visual Phenomenon**: The pouch features a clear vinyl front viewing window.
- **Failure Mode**: The naive algorithm saw the background through the vinyl and erased it. This eliminated the specular highlights, glare, and surface refraction that define clear plastic. The result rendered the pouch as an open, glassless frame.
- **Verdict**: **FAIL**. Transparent PVC requires physical specular preservation. The authentic original photograph is permanently enforced on the website.

### 3.2 AR-013 Heart Pouch Workbench Staging (`image copy 32.png`)
- **Visual Phenomenon**: An authentic behind-the-scenes photograph of the pink heart pouch on an artisan assembly cutting table with tools, measuring grids, and factory ambient lighting.
- **Failure Mode**: Cutting out the product destroyed the factory provenance and artisan storytelling value.
- **Verdict**: **FAIL (CONTEXTUAL ONLY)**. Retained exclusively as an authentic workshop documentary photograph.

## 5. Proposed Production-Grade Manual Masking Workflow

Until local AI model weights are provisioned, the only method capable of meeting ARMANO's luxury B2B standard is a **High-Precision Manual Vector Masking Workflow**:

```
+---------------------------------------------------------------------------------------------------+
| PRODUCTION-GRADE VECTOR CLIPPING & ALPHA MATTING WORKFLOW                                         |
+---------------------------------------------------------------------------------------------------+
|  1. PEN TOOL VECTOR CLIPPING PATH                                                                 |
|     - Draw precise sub-pixel Bezier curves along product boundaries (handles, straps, hardware).  |
|     - Cut out all interior negative spaces (e.g. between brush belt straps, inside tote handles).|
|                                                                                                   |
|  2. EDGE CONTAMINATION SUPPRESSION (COLOR DECONTAMINATION)                                       |
|     - For boundary pixels with 0 < alpha < 255:                                                   |
|       C_foreground = (C_observed - (1 - alpha) * C_background) / alpha                            |
|     - Neutralize pink/warm sweep spill using adjacent foreground hue clamping.                    |
|                                                                                                   |
|  3. SUB-PIXEL ALPHA FEATHERING (0.5 – 0.8 px)                                                     |
|     - Gaussian edge anti-aliasing to eliminate stair-stepping without blurring fine stitch lines. |

|  4. MULTI-SURFACE QA INSPECTION                                                                   |
```
