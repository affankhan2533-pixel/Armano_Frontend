## 3. Material & Substrate Library: Visual Observation vs. Technical Verification

> [!IMPORTANT]
> **MATERIAL COMPOSITION DISCLAIMER**:
> In compliance with technical auditing standards, visual surface characteristics observed from photography are strictly segregated from verified chemical and technical specifications. Exact material composition (e.g., polymer backing, GSM, yarn count, gauge thickness, tensile strength) remains **unconfirmed** pending client delivery of manufacturer Technical Data Sheets (TDS) or certified lab test reports.

### 3.1 Visually Observed Fabric & Surface Finishes `[VISUAL OBSERVATION]`
The physical sample archive demonstrates surface styling across several commercial finishes:
1. **Synthetic & Vegan Leather Finishes**:
   - Smooth Matte Leatherette Finish (white, red, blush, sage, terracotta)
   - Saffiano Crossgrain Embossed Texture
   - Pebbled / Drum-Dyed Grain Embossed Texture
   - High-Gloss Patent Finish (black, navy, lime)
   - Prismatic Holographic / Iridescent Sheen
2. **Textile & Woven Structures**:
   - Woven Canvas Appearance (natural, magenta)
   - Jacquard & Houndstooth Patterned Fabric
   - Coarse Multi-Ply Cord / Ribbed Weaves
   - Crinkle / Parachute Nylon-Style Textures
3. **Plush & Evening Substrates**:
   - Velvet / Velour Soft-Pile Texture
   - Satin / Silk-Like High-Luster Sheen
   - High-Pile Plush Faux-Fur / Teddy Fleece
   - Transparent Clear Vinyl Sheeting (window inserts)
4. **Quilted & Cushioned Construction**:
   - Square / Grid Puffer Padding
   - Vertical Channel Puffer Stitching
   - Chevron & Wave Quilted Patterns

### 3.2 Unconfirmed Technical Specifications `[UNCONFIRMED / PENDING LABORATORY TDS]`
The following technical parameters require formal confirmation via client Technical Data Sheets:
- Precise polymer base (PU vs. PVC vs. semi-PU) and backing substrate (TC, non-woven, microfiber).
- Fabric weight (GSM / oz) for canvas and nylon substrates.
- Gauge thickness (mm) for clear transparent vinyl.
- Flammability, REACH, RoHS, or migration certifications (none currently verified).

## 5. Dynamic Product Data Schema

To ensure seamless catalog filtering, search, and dynamic routing, all products follow this JavaScript object structure:

```javascript
/**
 * @typedef {Object} ArmanoProduct
 * @property {string} sku - Unique Stock Keeping Unit (e.g., 'ARM-AR001' through 'ARM-AR013')
 * @property {string} slug - URL slug (e.g., 'classic-zip-top-cosmetic-pouch')
 * @property {string} title - Human-readable product name
 * @property {string} category - Primary category identifier
 * @property {string} subcategory - Specific silhouette / style
 * @property {string[]} observedFinishes - Visually observed fabric/finish appearance
 * @property {string[]} brandingOptions - Supported branding methods
 * @property {Object} dimensions - Available sizing (pending exact confirmation)
 * @property {string} provisionalOrderScaleNotice - 'Provisional inquiry quantities: 10k / 20k / 50k (Client verbal indication)'
 * @property {string[]} provisionalRfqTiers - ['10,000', '20,000', '50,000']
 * @property {string[]} images - Primary and angle packshot paths
 * @property {boolean} is3DEnabled - Whether R3F 3D model exists
 * @property {string|null} model3dPath - Path to .glb asset in public/models/
 * @property {Object} seo - Metadata title, description, keywords
 */
```
