## 2. Interactive Mouse Parallax & Proximity Zoom Architecture

Inside `Hero3DCanvas.jsx`, the component `InteractiveParallaxStage` delivers dynamic, organic interaction without compromising drag-to-inspect rotation or touch controls:

### 2.1 Proximity Zoom & Parallax Physics
Let $(P_x, P_y)$ be the normalized pointer coordinates in $[-1, 1]$ relative to the canvas viewport:

$$d = \sqrt{P_x^2 + P_y^2}$$

Proximity factor:
$$p = \max\left(0, 1 - \frac{d}{1.35}\right)$$

Dynamic Transform Targets:
- **Proximity Zoom**: $S_{\mathrm{target}} = 0.98 + p \cdot 0.065 \implies [0.98, 1.045]$. As the cursor approaches the pouch, it gently enlarges to reveal fine quilted leatherette detail; moving away gently returns it to rest scale.
- **Parallax Position Offset**: $X_{\mathrm{target}} = P_x \cdot 0.08\,\mathrm{units}$, $Y_{\mathrm{target}} = P_y \cdot 0.05\,\mathrm{units}$.
- **Subtle Rotational Tilt**: $R_{y,\mathrm{target}} = P_x \cdot 0.06\,\mathrm{rad} \approx 3.4^\circ$, $R_{x,\mathrm{target}} = -P_y \cdot 0.04\,\mathrm{rad} \approx 2.3^\circ$.

### 2.2 Damped Interpolation Implementation
```jsx
const lerpSpeed = Math.min(1, delta * 3.0);
groupRef.current.position.x = THREE.MathUtils.lerp(groupRef.current.position.x, targetX, lerpSpeed);
groupRef.current.position.y = THREE.MathUtils.lerp(groupRef.current.position.y, targetY, lerpSpeed);
groupRef.current.rotation.x = THREE.MathUtils.lerp(groupRef.current.rotation.x, targetRotX, lerpSpeed);
groupRef.current.rotation.y = THREE.MathUtils.lerp(groupRef.current.rotation.y, targetRotY, lerpSpeed);
const newScale = THREE.MathUtils.lerp(groupRef.current.scale.x, targetScale, lerpSpeed);
groupRef.current.scale.set(newScale, newScale, newScale);
```
- Exponential damping ensures natural, weighted motion with zero jitter or snapping.
- When the mouse leaves the hero section, the pouch smoothly glides back to rest pose.
- Drag-to-rotate functionality via `OrbitControls` operates simultaneously without interference.

## 3. Controlled Scroll Depth Transition

In `HeroSection.jsx`, GSAP `ScrollTrigger` orchestrates an atmospheric receding depth effect:

```javascript
mm.add('(min-width: 1024px)', () => {
  gsap.to(rightColRef.current, {
    scale: 0.92,
    y: 28,
    opacity: 0.88,
    ease: 'power1.out',
    scrollTrigger: {
      trigger: sectionRef.current,
      start: 'top top',
      end: 'bottom top',
      scrub: 1.0,
    },
  });

  gsap.to(leftColRef.current, {
    y: -22,
    opacity: 0.88,
    ease: 'power1.out',
    scrollTrigger: {
      trigger: sectionRef.current,
      start: 'top top',
      end: 'bottom top',
      scrub: 1.0,
    },
  });
});
```
- As the user scrolls down, the 3D pouch gently scales from $1.0$ to $0.92$ and eases downward, appearing to recede deeper into the studio floor while transitioning toward the Manufacturing Divisions section.
- Scrolling back to the top seamlessly restores full scale and default elevation.
- Zero scroll hijacking; native scrolling velocity and physics remain 100% untouched.
