## 1. Frustum Framing & Aspect Ratio Mathematics

To guarantee that the 3D model maintains a minimum 15% visual breathing room and never suffers silhouette cutoff (puller tab, zipper crest, side gussets, or ground contact shadow) across dynamic viewport resizes, an `AdaptiveCameraRig` component was implemented in `Hero3DCanvas.jsx`:

### 1.1 Mathematical Formulation
Let $A = \frac{W}{H}$ be the viewport aspect ratio, with a fixed vertical field of view $\mathrm{FOV}_v = 35^\circ$:

$$\tan\left(\frac{\mathrm{FOV}_v}{2}\right) = \tan(17.5^\circ) \approx 0.3153$$

Visible vertical height at distance $Z$:
$$H_{\mathrm{visible}} = 2 \cdot Z \cdot \tan(17.5^\circ) \approx 0.6306 \cdot Z$$

Visible horizontal width at distance $Z$:
$$W_{\mathrm{visible}} = A \cdot H_{\mathrm{visible}} \approx 0.6306 \cdot A \cdot Z$$

On portrait mobile displays ($A \approx 0.46 - 0.54$), a fixed camera distance designed for widescreen desktop ($A = 1.6$) causes severe horizontal frustum clipping of the pouch side gussets and zip puller.

### 1.2 Adaptive Rig Implementation
The camera distance $Z$ and model scale $S$ dynamically adjust based on $A$:
- **Wide Desktop ($A \ge 1.15$)**: $Z = 4.60$, $S = 1.00$, $Y_{\mathrm{offset}} = -0.15$.
- **Portrait Mobile ($A < 1.15$)**: $Z = 5.25$, $S = 0.90$, $Y_{\mathrm{offset}} = -0.12$.

```jsx
function AdaptiveCameraRig() {
  const { camera, size } = useThree();
  useEffect(() => {
    const aspect = size.width / size.height;
    if (aspect < 1.15) {
      camera.position.set(0, 0.4, 5.25);
    } else {
      camera.position.set(0, 0.35, 4.6);
    }
    camera.updateProjectionMatrix();
  }, [camera, size.width, size.height]);
  return null;
}
```

This guarantees:
- Minimum horizontal margin: $\ge 18\%$ of viewport width.
- Minimum vertical margin: $\ge 22\%$ of stage height.
- Zero edge collision during continuous floating rotational bobbing ($\pm 0.08\,\mathrm{rad}$).
