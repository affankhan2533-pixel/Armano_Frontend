## 2. Root Cause Analysis: Resolving the User's Screenshot Issues

The user provided two critical screenshots from their browser (`localhost:3000` on Brave Browser):
1. **Screenshot 1 (Zoomed-In Macro Crop)**: The 3D cosmetic pouch was massively enlarged, cropped inside a rectangular stage, showing only giant quilted puff squares and a top brass sliver.
2. **Screenshot 2 (Blank Right Hero)**: The right side was completely empty—no 3D pouch, no fallback, and no swatches.

### Issue 1: Zoomed-in Cropped Box (Screenshot 1)
- **Root Cause**: During an earlier experimental "full-bleed hero background" attempt, the 3D canvas had its position set to absolute full-width with an overly tight camera FOV and unconstrained OrbitControls zoom. When constrained inside a parent container, the canvas aspect ratio was warped, zooming the camera directly into the front fabric face of the pouch.
- **Remediation**:
  - Restored the 58% right-column studio stage anchored at ~72% viewport width.
  - Locked camera distance to `targetZ = 4.6` on desktop and `5.15` on mobile via `AdaptiveCameraRig`.
  - Disabled mouse wheel zoom (`enableZoom={false}`) and pan (`enablePan={false}`) on `OrbitControls` to prevent accidental user scrolling from zooming into the mesh.
  - Bound the interactive parallax zoom to a subtle, luxury-grade scale delta (`0.98` to `1.045`).

### Issue 2: Completely Blank Right Hero (Screenshot 2)
- **Root Cause**: In Brave Browser, the default **Brave Shields "Fingerprint Protection"** blocks or restricts WebGL context creation (`getContext('webgl')` returns `null` or throws). In previous unhedged code, React Three Fiber threw an uncaught WebGL initialization exception. In React, an uncaught error unmounts the entire component tree, causing `<Hero3DCanvas>` (and its swatches) to vanish completely into a blank space.
- **Remediation**:
  - **Proactive Hardware/Browser Detection**: Implemented `getWebGLSupport()` using React's official `useSyncExternalStore` pattern. If WebGL is blocked by Brave Shields or hardware acceleration is unavailable, the component never attempts WebGL initialization.
  - **Graceful Error Boundary**: Wrapped the 3D canvas in a React `CanvasErrorBoundary` that catches any runtime context loss.
  - **High-Resolution Studio Photographic Fallback**: When WebGL is unavailable, a studio packshot of the authentic Quilted Pouch (`/images/products/AR-009.png`) renders seamlessly with natural drop shadows.
  - **Decoupled Swatch Controller**: The interactive swatch selector and concept badging are positioned outside the canvas boundary, remaining 100% visible and interactive across every browser.
