## 1. Motion Engine Architecture Clarification

### 1.1 Technical Stack
Contrary to external animation library assumptions, the ARMANO motion engine does **NOT** rely on external GSAP or ScrollTrigger npm dependencies. The implementation is lightweight, standards-compliant, and optimized for Next.js 16 App Router:

- **Intersection Observer Hook:** [`src/hooks/useScrollReveal.js`](file:///c:/Users/AFFAN%20KHAN/OneDrive/Desktop/ARMANO/src/hooks/useScrollReveal.js) monitors DOM elements using native browser observer APIs (`threshold: 0.15`, `rootMargin: '0px 0px -40px 0px'`).
- **Hardware-Accelerated CSS Transitions:** Transitions leverage GPU-composited properties (`transform`, `opacity`) with custom cubic-bezier timing curves (`cubic-bezier(0.16, 1, 0.3, 1)`).
- **Zero Layout Shifts:** No layout properties (`width`, `height`, `top`, `margin`) are animated during scroll, guaranteeing zero Cumulative Layout Shift (CLS = 0.00).

### 1.2 Verification of Interactive Motion Behaviors

| Feature | Implementation Mechanism | Verified Behavior |
| :--- | :--- | :--- |
| **Section Entrance Reveals** | CSS `.reveal-on-scroll` + `useScrollReveal` | Elements enter with a subtle 24px vertical lift and progressive opacity fade (0 -> 1) over 700ms with staggered delay indices (`0.1s`, `0.2s`, `0.3s`). |
| **Header Scroll Transition** | CSS backdrop filter + dynamic state | On scroll past 40px, navigation shrinks from 80px to 68px, background transitions to `rgba(7, 29, 22, 0.92)` with `backdrop-filter: blur(12px)` and gold hairline border reveal. |
| **Product Card Hover States** | CSS `transform: translateY(-4px) scale(1.02)` | Smooth 400ms easing with shadow intensification (`0 16px 32px rgba(0,0,0,0.12)`). Images scale gently at 1.03 without boundary clipping. |
| **Mobile Drawer Navigation** | CSS `transform: translateX(...)` + Focus Trap | Smooth slide-in from right edge (350ms `cubic-bezier(0.32, 0.72, 0, 1)`), dark scrim overlay fade, keyboard `Escape` key dismissal, and focus trapping. |
| **3D WebGL Idle Loop Pausing** | `IntersectionObserver` on Canvas parent | When the Three.js hero scrolls out of the active viewport, `cancelAnimationFrame` halts the WebGL render loop, reducing GPU/CPU consumption to 0%. Re-engages instantly upon scroll-up. |
| **Reduced-Motion Preference** | `prefers-reduced-motion: reduce` query | When the user OS requests reduced motion, all transforms and delays are disabled (`transform: none !important; transition-duration: 0.01ms !important`). |

## 3. Accessibility & Keyboard Navigation Verification

1. **Semantic HTML Landmarks:**
   - `<header role="banner">` wraps site navigation.
   - `<main id="main-content">` contains all primary editorial sections.
   - `<footer role="contentinfo">` wraps compliance links and facility credentials.
2. **Accessible Form Controls:**
   - RFQ Enquiry Modal inputs feature associated `<label>` tags with matching `htmlFor` and `id`.
   - Error messages are bound via `aria-describedby` and flagged with `aria-invalid="true"`.
3. **Keyboard Focus Management:**
   - Visible gold focus ring (`outline: 2px solid #C5A059; outline-offset: 2px`) is applied to all interactive elements on `:focus-visible`.
   - Mobile navigation drawer traps focus when open and returns focus to the trigger burger button upon close.
4. **Touch Target Dimensions:**
   - All buttons, navigation links, and swatch color selectors have a minimum tap target bounding box of 44 × 44 pixels.
