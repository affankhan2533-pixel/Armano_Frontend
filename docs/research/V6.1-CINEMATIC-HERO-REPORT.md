# ARMANO V6.1 — Cinematic Hero Re-Art Direction Report

## 1. Executive Summary & Problem Resolution
Following the user inspection of V6, the initial procedural hero was identified as appearing cartoon-like, boxed inside an artificial white rectangle card, with overly uniform puffy grid pillows and plastic-like specular lighting. 

**ARMANO V6.1** executes a complete luxury re-art direction:
- **Zero Boxed Card:** The 3D canvas is liberated from the previous rounded white box, extending into an immersive 90–100svh cinematic studio stage where the physical pouch and high-fashion editorial typography share the exact same room lighting and atmosphere.
- **Organic AR-009 Proportions:** Re-engineered directly against the authentic AR-009 photograph (`reference/product-images/image copy 19.png`), introducing realistic standing base wedge depth (0.92), gentle vertical taper (0.18 top), soft crest curvature with natural central fabric sag, and recessed stitched seam valleys.
- **PBR Micro-Texture Realism:** Procedural 256×256 in-memory cross-hatch fabric weave and tension bump texture applied to `MeshPhysicalMaterial`, providing realistic micro-light diffusion, sheen (0.45), controlled clearcoat (0.22), and authentic softbox highlights.
- **GSAP Scroll Choreography:** Seamless entrance sequence and subtle desktop-only scroll progression (`scrollTrigger` scrub: 1.2) without scroll-jacking.

## 3. Engineering Details

### 3.1 Organic Mesh Formulation
The pouch's procedural vertex calculation in `src/components/3d/QuiltedPouchMesh.jsx` computes volumetric loft using:
```javascript
// Authentic AR-009 crest sag under zipper weight
const centerSag = (1 - Math.pow(normX, 2)) * 0.028;
const shoulderFall = 0.16 * Math.pow(normX, 2.6);
const topY = (height / 2) * (1 - shoulderFall - centerSag);

// Cushion dome with steep recessed seam grooves
const domeU = Math.sin(cellU * Math.PI);
const domeV = Math.sin(cellV * Math.PI);
const puff = Math.pow(Math.max(0, domeU * domeV), 0.75);
const seamCrease = Math.pow(seamProximity, 4) * 0.025 * edgeTaper;
const zPuff = puff * 0.115 * edgeTaper - seamCrease;
```

### 3.2 GSAP ScrollTrigger Lifecycle
Implemented inside `src/sections/hero/HeroSection.jsx` using `gsap.context()` for clean React 19 lifecycle mounting and automatic unmount cleanup:
- **Mobile Guard:** ScrollTrigger pinning and desktop parallax are strictly guarded by `gsap.matchMedia('(min-width: 1024px)')`. Touch scrolling on iOS and Android remains 100% native.
- **Accessibility:** Respects `prefers-reduced-motion: reduce`, defaulting to instant opacity states.
